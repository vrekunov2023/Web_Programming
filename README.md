# Лабораторна робота 2

Простий статичний багатосторінковий web-сайт, створений у рамках виконання лабораторної роботи з дисципліни «WEB-програмування». 

## Опис проєкту
Проєкт являє собою мінімалістичний блог, що складається з кількох взаємопов'язаних сторінок. Головна тема — три українські міста: Львів, Київ та Кривий Ріг. В оформленні використано строгий чорно-білий стиль.

## Структура файлів
- `index.html` — головна сторінка.
- `city-lviv.html`, `city-kyiv.html`, `city-kryvyi-rih.html` — сторінки, присвячені окремим містам.
- `form.html` — сторінка з HTML-формою для пропозиції нових міст.
- `images/` — каталог із зображеннями.

## Технології
- HTML5 (семантична розмітка)
- Вбудований CSS (мінімальна стилізація та фільтри)
- Git / GitHub Pages (контроль версій та розгортання)
